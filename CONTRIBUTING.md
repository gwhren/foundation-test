# Contributing

This repository is used to test Foundation agents, roles, rights, and sandboxes.
Read `README.md` for context, keep changes focused on the task, and describe what
changed and how you checked it so reviewers can assess the contribution.

## How to run

There is currently no runnable application or script in this repository, so there
is no local run command or installation step. For documentation changes, review
the Markdown for clarity and accuracy and use `git diff --check` to check tracked
changes for whitespace errors.
